# Zenmanage

Zenmanage is a feature flag and remote configuration platform. Roll out features progressively, target specific users and segments, and adjust behavior at runtime — without redeploying code.

- [zenmanage.com](https://zenmanage.com)
- [Documentation](https://zenmanage.com/developers)
- [Quickstarts](https://zenmanage.com/developers/quickstarts)
